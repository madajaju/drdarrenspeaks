# DrDarrenSpeaks.com Site Punchlist

## Goal

Rework `drdarrenspeaks.com` so it clearly functions as Dr. Darren’s premium speaking, authority, and booking site.

The site should answer one primary question:

> Why should an event planner, executive team, university, or association hire Dr. Darren?

The site should not try to be the home for AI-Augmented methodology, consulting implementation, or podcast content. Those should point to the correct related properties.

---

# Phase 1 — Inventory Current Site

Before making changes, inspect the existing source site pages directory.

## 1.1 Inventory Pages

Create a list of all current pages in the site.

For each page, document:

* File path
* Page title
* Meta title
* Meta description
* H1
* Primary CTA
* Secondary CTA
* Internal links
* External links
* Images used
* Forms used
* Schema markup present
* Whether the page appears active, outdated, duplicate, or unnecessary

Output this as:

```md
## Current Page Inventory

| File | Page Purpose | Keep / Rewrite / Remove / Redirect | Notes |
|---|---|---|---|
```

---

## 1.2 Inventory Navigation

Document the current navigation structure.

Identify:

* Main nav items
* Footer nav items
* Repeated links
* Broken links
* Links to old pages
* Links that should point to other properties

Recommended final navigation:

```text
Home
Speaking
Workshops
Books
Media Kit
About
Contact
```

Remove or demote:

```text
Community
Interviews
Works
Generic Resources
Podcast-first pages
```

---

Search the site for outdated or weak positioning language.

Flag phrases such as:

* Generative AI speaker

Replace with stronger positioning around:

# Phase 4 — Content Cleanup

## 4.1 Remove Duplicate or Weak Pages

After inventory, identify pages that should be removed, redirected, or merged.

Likely candidates:

* Old community pages
* Old interview pages
* Generic resources pages
* Generic “works” pages
* Podcast-heavy pages
* Pages that duplicate EmbracingDigital.org

For each removed page, add a redirect where appropriate.

---

## 4.2 Cross-Link Correctly

Use the four-property model:

| Destination            | Use For                                                          |
| ---------------------- | ---------------------------------------------------------------- |
| `aiaugmented.ai`       | AI-Augmented methodology, AAOS, assessments, certification       |
| `paidar.ai`            | Consulting, implementation, training, workshops as paid services |
| `embracingdigital.org` | Podcasts, articles, digital transformation research, ODXA        |
| `drdarrenspeaks.com`   | Speaking, media kit, books, authority, booking                   |

Do not let DrDarrenSpeaks.com become the content hub for everything.

---

## 4.3 Add Strong CTAs

Every page should have one primary CTA.

Preferred CTAs:

* Book Dr. Darren
* View Speaking Topics
* Download Media Kit
* Invite Dr. Darren to Speak
* Request Availability

Avoid vague CTAs:

* Learn More
* Explore
* Click Here
* Get Started

# Phase 7 — Technical Cleanup

## 7.1 Check Internal Links

Run a local link audit.

Fix:

* Broken links
* Old Zoho URLs
* Links to removed pages
* Mixed http/https links
* Links with tracking artifacts
* Inconsistent trailing slashes

---

## 7.2 Check Images

For every image:

* Confirm file exists
* Compress image
* Add descriptive alt text
* Use consistent dimensions
* Avoid large unoptimized hero images
* Replace generic stock AI images where possible

---

## 7.3 Check Accessibility

Ensure:

* One H1 per page
* Correct heading order
* Button text is descriptive
* Links are keyboard accessible
* Images have alt text
* Color contrast passes WCAG AA
* Form fields have labels

---

## 7.4 Check Performance

Optimize:

* CSS
* JavaScript
* Images
* Font loading
* Unused assets
* Large third-party scripts

Site should be fast and lightweight.

---

# Phase 8 — Final Acceptance Criteria

The site is complete when:

* The homepage clearly positions Dr. Darren as an AI-Augmented leadership keynote speaker.
* The primary CTA is “Book Dr. Darren.”
* The site no longer feels like a generic technology speaker site.
* The navigation is simple and focused.
* Books are visible as authority assets.
* Media kit materials are easy to find.
* Speaking topics are clear and premium.
* Workshops are positioned as executive enablement.
* Cross-links route visitors to the correct related properties.
* SEO metadata exists on every page.
* Schema markup is present.
* No broken links remain.
* No outdated 2023-style AI positioning dominates the site.
